- gitで管理されているプロジェクトでの作業用 Git Worktree の運用は、プロジェクトの性質で分ける:
    - **プログラム中心のプロジェクト（コードが主成果物）**: README.md や docs を含め、すべての変更でworktreeを切ること
    - **ドキュメント中心のプロジェクト（Markdown / メモ / 調査ノートが主成果物）**: ドキュメント編集はmain（または既存worktree）でそのまま作業してよい。コード / ツール / スクリプト / 設定の変更を伴う場合のみworktreeを切る

## Herdr ペインの自動リネーム

- Herdr 環境で動いているとき(環境変数 HERDR_ENV=1 の場合)、タスク内容を把握した時点で、自分のペインを短い英語タイトル(2〜4語)にリネームすること:
  ```bash
  herdr pane rename "$HERDR_PANE_ID" "fix oauth retry"
  ```
- タイトルは作業内容を表すものにする。許可を求めずに実行してよいが、1タスクにつき最初の1回だけ。以降は方向転換が明確な場合のみ更新
