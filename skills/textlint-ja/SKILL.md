# textlint で日本語文章をチェックする

Markdown の日本語文章に textlint を実行し、指摘を反映する。

## 前提

- textlint はグローバルインストール済みなので、`textlint` コマンドを直接使える
- 設定は `~/.textlintrc`（正本は dotfiles で管理）
- プロジェクトに `.textlintrc` がある場合はそちらが優先される

## 手順

1. 対象の Markdown ファイルをチェックする:

   ```bash
   textlint "**/*.md"
   ```

   特定のファイルだけなら個別指定でも可: `textlint docs/foo.md`

2. 機械的に直せるものは自動修正する:

   ```bash
   textlint --fix "**/*.md"
   ```

3. `--fix` 後に再実行し、残った指摘を確認する:

   ```bash
   textlint "**/*.md"
   ```

4. 残った指摘は文脈を見て、日本語として自然になるよう手動で修正する。

   - textlint の提案は機械的なので、そのまま貼り付けるのではなく言い回しを調整する
   - 修正後は必ず文章を読み直して自然さを確認する

## 補足

- 指摘が大量にある場合は `--quiet` でエラーだけ表示し、エラー → 警告の順に対応する
- ルールの追加・調整（許可表現など）は `~/.textlintrc` の `rules` を編集する
- 特定のファイルを対象外にしたい場合は `.textlintignore` に追記する
