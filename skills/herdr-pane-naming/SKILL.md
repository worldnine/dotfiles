# Herdr pane naming

Herdr のペイン/タブ名を、作業内容を表す短い英語タイトルに保つための規約。

## いつやるか

- `HERDR_ENV=1` で動いていて、**タスク内容を把握した時点**で実行する
- ユーザーに許可を求めない。1タスクにつき最初の1回だけ
- 作業の方向転換が明確な場合のみ更新する

## コマンド

```bash
herdr pane rename "$HERDR_PANE_ID" "fix oauth retry"
```

`$HERDR_PANE_ID` は Herdr が注入する環境変数。存在しない場合は Herdr 外なので何もしない。

## 命名ルール

- **英語**で書く(OSS・ペアプロ・画面共有など海外の目に触れる前提)
- **2〜4語、できれば20文字以内**
- 形は動詞起点の要約: `fix oauth retry`, `add csv export`, `refactor session store`
- 記号はスペースとハイフン程度。スラッシュやコロンは使わない
- 情報が少なすぎてまともな名前が付けられないときは、無理に付けず次のユーザー発言を待つ

## 避けるべきもの

- 日本語(表示はできるが共有シーンを考慮して英語固定)
- `work`, `task`, `temp`, `test` などの情報量ゼロの語
- herdr が自動生成したランダム名(`brave-meadow-4aa8` 形式)の放置

## 補足

- pi を使っている場合は `@henryqw/pi-herdr-rename` 拡張が会話から自動生成するので、このスキルの手動リネームは通常不要
- ブランチ名はこの規約の対象外(既存ブランチは勝手に変えない)
